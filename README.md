# 日语学习站（零基础 → N2 → N1）

纯静态、离线可用的日语自学 Web App。无后端、无构建框架，双击 `dist/index.html` 即可使用，或用 Netlify 从本仓库自动部署。

线上地址：https://ryuxuexi.netlify.app

## 内容规模

| 项目 | 数量 |
|---|---|
| 词汇 | 1582（N5 528 / N4 500 / N3 176 / N2 200 / N1 178） |
| 语法 | 214 条（N5 55 / N4 46 / N3 40 / N2 39 / N1 34） |
| 动词 | 174（11 种变形由引擎自动推算） |
| 形容词 | 69 |
| 假名 | 103（含字源、例词、9 组易混对） |
| 真人发音 | 1121 条母语者录音索引 |

## 功能模块

1. **首页** — 今日任务、五级掌握度、未来 7 天复习量预测
2. **五十音** — 认读 / 辨形 / 易混对专项，可发音，带字源速查表与五十音图
3. **单词卡** — SM-2 间隔重复，四档评分，按级别/课号筛选
4. **语法库** — 五级检索 + 全文搜索，例句可发音，可标记掌握
5. **变形训练** — 动词 11 种形 + 形容词 8 种形，输入判分，含规则速查表
6. **我的词库** — 自定义单词/语法，按等级并入复习队列；支持批量导入
7. **仪表盘** — 打卡、连续天数、12 周热力图、成就、进度导出/导入

## 发音系统

三层自动回落：**真人录音 → TTS 神经语音 → 用户指定**。

- 真人音来自 JapanesePod101 公开词典，由 Service Worker 缓存（`jp-audio-v1`），缓存后秒播、可离线
- 未缓存时 2.5 秒未出声会用 TTS 兜底，不干等
- 系统无日语语音时不朗读，避免用中文语音念日语
