# 日语学习站 · 零基础 → N2 → N1

一个**纯静态、离线可用**、无需注册登录的日语自学 Web App。基于《新版中日交流标准日本语》体系，覆盖 N5 到 N1 五个等级，内置间隔重复记忆（SRS）、动词变形训练、真人发音与学习仪表盘。

- 🌐 **在线地址**：https://ryuxuexi.netlify.app
- 📦 **仓库**：`git@github.com:lxrchen/ryuxuexi.git`
- 🔧 **技术**：原生 HTML / CSS / JavaScript，零依赖、无框架、无后端

> 所有学习进度保存在浏览器本地（localStorage），不上传服务器。

## 快速开始

**方式一：直接用线上版**

打开 https://ryuxuexi.netlify.app ，手机浏览器点「添加到主屏幕」即可当 App 用（PWA，离线可用）。

**方式二：本地双击**

```bash
node build.js          # 生成 日语学习站_单文件版.html
```

双击桌面上的 `日语学习站_单文件版.html` 即可，不依赖服务器和网络。

**建议的学习顺序**

1. **五十音** — 先把假名焊死（平假名 + 片假名 + 浊音拗音），尤其看「九组易混对」
2. **单词卡** — 每天 20 个新词 + 到期复习，先打满 N5（528 词）再进 N4
3. **语法库** — 学到对应课时按等级查阅，标记已掌握
4. **变形训练** — 从第 5 课（动词ます形）开始成为主力，这是串起全书的主干

## 功能模块

### 1. 首页
今日任务卡片（待复习 / 新词 / 变形练习）、五级掌握度进度条、未来 7 天复习量预测柱状图、今日目标进度环。

### 2. 五十音
三种练习模式：**认读**（看假名选罗马字）、**辨形**（看罗马字选假名）、**易混对专项**。配套字源速查表（每个假名来自哪个汉字）、可点击发音的五十音图、浏览器日语朗读。

### 3. 单词卡（SRS）
- **SM-2 间隔重复算法**，四档评分（忘记 / 困难 / 良好 / 简单）自动排复习
- 3D 翻转卡片：正面回忆 → 翻面评分
- 可按**级别**、按**课号 / 主题**筛选
- 评「忘记 / 困难」自动进错词本
- 命中真人音库时显示绿色「真人」角标

### 4. 语法库
五级检索 + 全文搜索，点击展开例句（可发音），可标记已掌握，支持用户添加自己的条目。

### 5. 变形训练
动词 **11 种形**（ます / て / た / ない / 可能 / 意志 / 受身 / 使役 / 条件 / 命令 等）+ 形容词 **8 种形**（て / た / ない / 过去否定 / 副词化 / ば / 连体）。输入判分，答错显示对应规则，含完整规则速查表。

> 动词只需录入「基本形读音 + 类型」，11 种变形全部由 `conj()` 自动算出，不需要手写。

### 6. 我的词库（自定义内容）
可添加自己的单词与语法，**按指定等级并入对应复习队列**，与内置内容一起复习、一起统计进度：
- 单词 → 并入该等级的单词卡队列
- 动词（填基本形）→ 自动进入变形训练池；填ます形会自动转换（`たべます → たべる`）
- 语法 → 并入语法库，可按等级筛到

支持**批量导入**（每行一条，制表符 / 逗号 / 空格分隔，2–4 列自动识别，也支持粘贴 JSON），以及 JSON 导出。

### 7. 错词本
自动收集评「忘记 / 困难」的卡片，一键重练。

### 8. 仪表盘
打卡与连续天数、12 周活跃热力图、分级进度、假名薄弱项排名、成就徽章（9 枚）、XP 与等级、**进度导出 / 导入**（换设备迁移）、**真人音缓存管理**。

## 发音系统

三层自动回落，目标是「尽量用真人声，实在没有才用合成音」。

```
① 真人录音（1121 词，母语者）
      ↓ 未命中 / 加载失败
② TTS 神经语音（自动挑设备最好的日语语音）
      ↓ 系统无日语语音
③ 不朗读（提示安装语音包，避免用中文语音念日语）
```

### 真人音

音源为 JapanesePod101 公开词典音频，实测**延迟 7.6–9.2 秒、约 1/3 概率超时、无 CORS 头**——所以缓存是刚需：

- 由 **Service Worker 拦截 `<audio>` 请求**落缓存（跨域资源无 CORS，页面端 fetch 会失败，只能走 SW）
- 缓存名 `jp-audio-v1`，与页面资源缓存 `jp-study-v1` 分开管理
- 缓存后**秒播、可离线**
- 未缓存时若 **2.5 秒**未出声，先用 TTS 发声，音频继续后台加载，下次即命中——不干等
- 单词卡会自动后台预热**下一张卡**的音频
- 仪表盘可一键「缓存 N5 / 当前目标 / 全部」

### TTS 语音优选

自动打分挑选设备最优日语语音：

| 语音 | 分值 | 说明 |
|---|---|---|
| Google 日本語 | +100 | Chrome / Edge 云端神经网络音，质量最好 |
| Aoi / Naoki / Shiori / Keita | +80 | Windows 11 神经语音包 |
| Ayumi / Ichiro / Haruka | +20 | 老式 SAPI 语音 |
| eSpeak / Pico | −60 | 机械音，尽量不选 |

Windows 11 安装神经语音包：设置 → 时间和语言 → 语言和区域 → 日本語 → 语言选项 → 语音。

## 技术架构

```
┌─────────────────────────────────────────────┐
│  数据层  js/data/*.js                        │
│  kana / vocab-N5~N1 / verbs / grammar /     │
│  audio-map（真人音索引）                     │
└──────────────────┬──────────────────────────┘
                   ↓  normVocab() 归一化
┌─────────────────────────────────────────────┐
│  运行时视图  VOCAB / VERBS / GRAMMAR         │
│  = 内置 BASE + 用户自定义（rebuildAll 合并） │
└──────────────────┬──────────────────────────┘
                   ↓
┌─────────────────────────────────────────────┐
│  引擎  js/app.js                             │
│  SRS(SM-2) / 变形 conj() / 路由 / 视图渲染   │
│  真人音 speak() / 缓存 warmAudio() / 统计    │
└──────────────────┬──────────────────────────┘
                   ↓
┌─────────────────────────────────────────────┐
│  持久化                                      │
│  localStorage: jp_studio_v1（进度/自定义词） │
│  Cache API:    jp-study-v1（页面）          │
│                jp-audio-v1（真人音）        │
└─────────────────────────────────────────────┘
```

**关键设计**

| 设计 | 说明 |
|---|---|
| 单文件产物 | `build.js` 把 CSS + 8 个数据文件 + 主程序内联进一个 HTML，双击即用 |
| 内置 / 自定义分离 | 内置数据不可变（`*_BASE`），运行时视图由 `rebuildAll()` 合并，业务调用点无需关心 |
| 变形引擎 | `conj(kana, type, form)` 按规则推算，含 `行く→行って`、`ある→ない`、`来る→こない` 等特殊形 |
| 语音防串台 | `playHuman()` 用 `settled` 单锁，保证回落只发生一次；无日语语音时不朗读 |
| 无网络依赖 | PWA + SW 预缓存，装到桌面后可完全离线使用 |

**存储结构**（localStorage `jp_studio_v1`）

```js
{
  settings: { goal, newPerDay, kanaScript, audioMode, voiceURI, ttsRate, humanRate },
  cards:    {},      // 单词 SRS：id -> { i, ef, n, due }
  kanaStat: {},      // 假名统计：kana -> { r, w }
  grammar:  {},      // 已掌握语法 id
  drill:    { r, w, log },
  checkin:  { days, streak, last },
  today:    { date, new, rev, drill, min },
  act:      {},      // 日期 -> 活动量（热力图）
  xp, combo, best, wrong, badges,
  custom:   { vocab: [], grammar: [] }   // 用户自定义词库
}
```

## 部署

### Git 自动部署（当前方式）

Netlify 已连接本仓库，push 后自动构建（约 1–2 分钟生效）：

```bash
git add -A
git commit -m "说明改了什么"
git push
```

`netlify.toml`：

```toml
[build]
  command = "node build.js"
  publish = "dist"
```

认证使用 **SSH 密钥**（`~/.ssh/id_ed25519`）。GitHub 自 2021 年起不支持账号密码推送，只能用 SSH 或 Personal Access Token。

### 手动部署（备用）

登录 https://app.netlify.com → 站点 `ryuxuexi` → Deploys → 把 `日语学习站_dist` 整个文件夹拖进去覆盖。

> 建议只用其中一种，混用可能造成版本回退。

## 扩充内容

**N5 词表**（数组格式）：

```js
[课号, "假名", "汉字表记", "中文", "词性"]
[1, "ちゅうごくじん", "中国人", "中国人", "名"]
```

**N4–N1 词表**（对象格式）：

```js
{ l: 课号或主题号, k: "假名", w: "汉字表记", z: "中文", p: "词性" }
```

**动词**：`["读音", "汉字", 类型, "中文", "等级"]`，类型 `1`=一类(五段) `2`=二类(一段) `3`=三类
**形容词**：`["读音", "汉字", "形1"/"形2", "中文", "等级"]`
**语法**：`["等级", "课号", "条目", "接续", "意思", "例句", "翻译"]`

词性可选值：`名` / `动1` / `动2` / `动3` / `形1` / `形2` / `副` / `连体` / `叹` / `助` / `接` / `代`

扩充词表后，建议重新扫描真人发音索引：

```bash
node tools/probe-audio.js    # 约 10–15 分钟，输出 js/data/audio-map.js
node build.js
```

更多细节见 `维护说明.md`。

## 浏览器支持与已知限制

- **推荐** Chrome / Edge（有「Google 日本語」云端神经语音，音质最好）
- PWA 安装需 HTTPS 环境（线上地址满足；本地双击版不支持）
- Safari 需要系统安装日语语音包才能 TTS 发声
- 进度存 localStorage：**换浏览器或清缓存会丢失**，换设备请用仪表盘的「导出 / 导入」
- 纯静态无后端：多设备进度不自动同步
- 真人音依赖第三方公开词典（境外服务器），缓存后离线可用；未缓存时可能较慢
- 页脚版本戳显示的是**构建机 UTC 时间**，比北京时间晚 8 小时
